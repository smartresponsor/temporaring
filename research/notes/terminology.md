# Canonical terminology

- repository: `temporaring`;
- engineering component: `Temporaring`;
- research/physical concept: `System Tempo`;
- Composer package: `temporaring/tempo`;
- PHP namespace: `App\Temporaring\`;
- PHP subject prefix: `Tempo*`;
- component-owned YAML prefix: `tempo_*`.

`Temporaring` and `System Tempo` are not synonyms.

**Tempo factor (`Gamma`)** is a multiplier applied to model dynamics; its appearance in an
equation does not make it physically observable.

**Time reparameterization** changes the parameter used to traverse a trajectory.

**Relative tempo** is a relation such as `Gamma_A / Gamma_B` between dynamically active components, interesting only when it is symbolically nontrivial and affects an invariant or operational observable.

**Hypothesis** is the central immutable scientific claim. **Experiment** is a deterministic
test specification. **Run** is one execution. **Evidence** is reproducible output. **Verdict**
is the scoped deterministic interpretation of that evidence.

Distinguish established mathematics, implemented deterministic results, physical hypotheses,
conjectures, and philosophical motivation.
