# System Tempo v0.1 scope

v0.1 asks one narrow question: for a deterministic classical ODE model, is a proposed tempo
factor removable as time reparameterization, or does the model survive that first no-go
filter? It is intentionally not a universal physics engine.

Included model class:

- deterministic, classical, finite-dimensional systems;
- smooth ODE dynamics;
- real-valued tempo factors;
- autonomous baseline dynamics;
- declared positive `Gamma` as the primary no-go baseline; v0.1 does not yet prove global positivity except for detecting obvious symbolic contradictions such as an identically zero active factor;
- symbolic classification before numerical integration.

The implementation permits one global factor or one factor per state component. Component-wise compatibility is evaluated only on dynamically active baseline components; factors attached to identically zero components are dynamically irrelevant to the v0.1 reparameterization test.

Before expensive simulation prefer contract validation, dimensional sanity where available,
symbolic simplification, reparameterization, symmetry, conservation, and known-limit tests.

v0.1 does not attempt quantum mechanics, GR replacement, cosmological claims, stochastic
systems, PDE/field theory, GPU/HPC, neural surrogates, or agent swarms as scientific
authorities.

Unsupported model classes should be labeled `outside_v0_1_scope` with an `inconclusive`
verdict unless a narrower deterministic rule applies.
